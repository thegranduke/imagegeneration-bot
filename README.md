# AI Image Generation Discord Bot

## Overview
A Discord bot that generates images using AI based on user prompts.

## Features
- Text-to-image generation
- Real-time image creation
- Error handling
- Simple Discord integration

## Installation
1. Clone the repository
2. Install dependencies: `pip install discord.py requests`
3. Set up a Discord bot token
4. Run the script

## Usage
`!imagine a futuristic cityscape at sunset`

## Technologies
- Python
- discord.py
- Pollinations AI
- Requests
